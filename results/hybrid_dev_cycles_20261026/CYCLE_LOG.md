**Current-drift investigation (WS3, calibration + validation runs):**
- The 135-sample exclusion window left 15 usable samples per 150-sample segment for `DUT_I12` and 65 for the others. With min_series = 60, post-onset segments were skipped.
- For the self-heating channel `DUT_I13`, the pre-onset error σ is 1.18 mA against the expected √(σ_DUT² + σ_ref²) = 0.30 mA. The thermal transient that the static calibration cannot represent dominates.
- For `I11`/`I12` the error σ (0.16 / 0.19–0.21 mA) matches the DUT + reference budget, so the reference uncertainty contributes about 10 % of the variance and is not limiting.
- The fix came from tuning: a 90-sample exclusion, run-mode baseline with min_baseline 90, k = 2, h = 12.

After freezing: v4 suite generated (`config/synthetic_suite_v4_config.json`, test runs only, new seed roots), and the frozen bundle was scored once (`results/hybrid_final_20261026_123148`).
